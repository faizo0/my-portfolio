# Muhammad Faizan (محمد فیضان) — React.js & Three.js 3D Portfolio

## Laptop par run karne ka tarika (How to Run Locally)

1. Is ZIP file ko extract karein.
2. Folder ko **VS Code** mein open karein aur Terminal kholein (`Ctrl + ~`).
3. Dependencies install karein:
   ```bash
   npm install
   ```
4. Development server start karein:
   ```bash
   npm run dev
   ```
5. Terminal mein jo link aaye (e.g., `http://localhost:5173`) usay browser mein open karein.
